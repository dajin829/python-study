## 学到哪了（Day 1 → Day 19 已完成）

| 阶段 | 内容 |
| --- | --- |
| 基础语法 | `print`、变量、`input` / `int()` / `float()`、字符串方法、运算符 |
| 控制流 | `if` / `elif` / `else`、循环嵌套、`while` + `break` |
| 数据结构 | 列表（增删查改、遍历、切片）、字典（取值 / 嵌套）、集合（去重） |
| 进阶 | 函数（`def`、参数、`return`、默认参数）、模块 `import`、文件读写（`open` / `with`） |

每个 `dayXX.py` 就是当天练习代码，能直接跑。

## 怎么跑

```bash
cd python-study
python day19.py   # 把 19 换成任意天数
```

需要本地装好 Python 3。
