# 每日天气小工具

一个查各个城市天气的命令行小工具
 
## 能干什么

- 输入1汇报对应城市的天气，湿度，温度，并将每次查询结果追加存进 weather.txt
- 输入"2"，显示之前查过的所有城市记录
- 输入"3"，就是退出这个程序


## 怎么运行

第一步，装依赖（只需要装一次）：

```
pip install requests
```

第二步，运行：

```
python main.py
```

跑起来会看到菜单：输入 1 查天气，2 看历史，3 退出。

## 说明

weather.txt 是程序自动生成的，不用手动创建
查不到的城市不会写进文件
